# Travel & Lodging Evaluation Research

## HotelQuEST

HotelQuEST is a hotel-search benchmark covering 214 queries from simple factual requests to complex hotel-search tasks. It explicitly evaluates quality together with cost, token usage and latency, and includes complexity ratings, ground-truth clarifications and structured query decompositions.

Source: https://github.com/amazon-science/hotel-quest-benchmark

## TravelEval

TravelEval proposes six dimensions for travel planning evaluation: accuracy, compliance, temporality, spatiality, economy and utility. It uses realistic accommodation pricing, transport data and simulation-based evaluation.

Source: https://arxiv.org/abs/2606.01046

## TREK

TREK provides a deterministic, rule-based evaluator for complex travel plans. It evaluates constraint satisfaction, truthfulness, executability and infeasibility handling, with efficiency reported separately. It is especially useful as a model for deterministic travel-domain grading.

Source: https://github.com/TonyQJH/TREK-A-Travel-Reasoning-and-Evaluation-Kit-for-LLM-Agents-in-Complex-Trip-Planning

## WebTailBench

WebTailBench includes hotel, flight, activity and compositional travel tasks with machine-readable rubrics. It is useful for broad regression and long-tail web-search coverage.

Source: https://huggingface.co/datasets/microsoft/WebTailBench

## Expedia LTR

The Expedia LTR project is useful as a conventional hotel retrieval/ranking reference, particularly for Recall@K, NDCG and MRR-style metrics.

Source: https://github.com/matthewevans87/expedia-ltr

## Retrieval Evaluation Demo

A compact reference implementation for retrieval evaluation metrics including Precision@K, Recall@K, NDCG and MRR.

Source: https://github.com/hweller1/retrieval_eval_demo
