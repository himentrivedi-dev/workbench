# 06 — Retrieval

## Purpose

Move from one-size-fits-all RAG toward retrieval strategies selected by the query and data characteristics.

## Patterns

- Structured filtering for exact constraints.
- Lexical search for names and identifiers.
- Semantic/vector search for concepts and preferences.
- Geospatial retrieval for distance and location intent.
- Agentic retrieval for iterative decomposition and follow-up retrieval.
- OKF/RAG for stable curated knowledge such as tool contracts, policies and business rules.

## Travel rule

Agentic search does **not** make vector search obsolete. Hotel/activity discovery should use hybrid retrieval; price and availability remain dynamic source-of-truth data.
