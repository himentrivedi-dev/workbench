# Security Policy

## Supported versions

Security fixes are provided for the current state of the default branch (`main`). Older snapshots and branches may not receive security updates.

## Reporting a vulnerability

Please do **not** report suspected vulnerabilities in a public GitHub issue, discussion, or pull request.

Use GitHub's **Private vulnerability reporting** feature from this repository's **Security** tab (when enabled) to send a confidential report. If that feature is unavailable, contact the repository owner privately through their GitHub profile and do not publish exploit details.

Please include, where possible:

- A concise description and potential impact
- Steps to reproduce or a proof of concept
- Affected paths, commits, or versions
- Any suggested mitigation

Please allow reasonable time for investigation and remediation before public disclosure. Do not access, modify, or disclose data that is not yours while validating a report.

## Secrets accidentally committed

If you discover a credential or token in this repository, notify the owner privately. The credential should be revoked or rotated immediately. Removing it from the latest commit does not invalidate it and does not remove it from Git history or existing clones.
